## Card options

The card offers a *lot* of configuration options!  You may find it simpler to use the UI, but if you need to edit the YAML directly it's all documented here.

The only configuration required is `type: custom:energy-distribution-ext`: this will set the card up to mimic the official Energy Distribution Card without any further tweaking needed.

Some options are mode-specific: they will only work in either `energy` or `power` mode.  It is always safe to leave these options in your config; they will be ignored if not used.

| Name                 | Type                                                                                                                | Default                                                                                                 | Description                                                                                                                                         |
|----------------------|---------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| `type`               | `string`                                                                                                            | **required**                                                                                            | Must be set to `custom:energy-distribution-ext`                                                                                                     |
| `mode`               | `energy \| power`                                                                                                   | `energy`                                                                                                | Selects whether the card should display energy or power flows                                                                                       |
| `title`              | `string`                                                                                                            |                                                                                                         | Shows a title at the top of the card                                                                                                                |
| `use_hass_config`    | `boolean`                                                                                                           | `true`                                                                                                  | Loads the entities configured for the [HASS Energy Dashboard](http://homeassistant.local:8123/config/energy)                                        |
| `date_range`         | `today \| this_week \| this_month \| this_quarter \| this_year \| now-7d \| now-30d \| now-12m \| from_date_picker` | `from_date_picker` if an `energy-date-selection` card is present in the dashboard;<br>`today` otherwise | The date-range to display<br>(`energy` mode only)                                                                                                   |
| `date_range_live`    | `boolean`                                                                                                           | `false`                                                                                                 | Include the latest data from the entities<br>(`energy` mode only)                                                                                   |
| `date_range_display` | `do_not_show \| label \| controls`                                                                                  | `do_not_show`                                                                                           | Display the selected date-range at the top of the card, optionally with controls to navigate backwards and forwards in time<br>(`energy` mode only) |

| `home`               | [`Home`](home.md)                                                                                                   |                                                                                                         | Home options section                                                                                                                                |
| `low-carbon`         | [`Low-carbon`](low-carbon.md)                                                                                       |                                                                                                         | Low-carbon options section                                                                                                                          |
